# CreatorOS — Custom Camera Firmware Research

Research project exploring whether a budget Wi-Fi digital camera (bought on
TikTok Shop, brand and model unknown) can run custom firmware, and if not,
what a realistic "CreatorOS" experience could look like instead.

**Current phase: Phase 1 — Hardware identification (read-only).**

Start here: [`research/README.md`](research/README.md)

## Ground rules

1. Do not flash, erase, or modify any physical device.
2. Do not assume the camera runs Linux, Android, or any particular chipset.
3. Identify the hardware from evidence: labels, USB information, firmware
   version, regulatory filings, and documentation.
4. Use only safe, read-only inspection methods on macOS.
5. Research open-source firmware **only after** the chipset is identified.
6. If full firmware replacement is not feasible, pursue a realistic
   alternative.
7. Preserve original camera functionality; a verified backup must exist
   before any future modification is even discussed.

This repository contains **no flashing commands, firmware images, or
installation procedures**, by design.
